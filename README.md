# Nogin.nl
[![php](https://img.shields.io/badge/PHP-^8.4-brightgreen?logo=php&style=flat&logoColor=lightgrey)](https://www.php.net/supported-versions.php)

>**NOTE:** This is a largely vibe-coded low-effort fun little hobby project 

Toggle whether you are still in NL or not, for everybody to see and modify! What could go wrong?!

# Is or Isnt in NL

use URL `https://is<name>.nogin.nl` to view a dedicated page showing whether that person is still in NL. 

# REST API
api.nogin.nl has documentation on how to use the singular "/persons" endpoint
