API reference

Nogin.nl REST API

Simple endpoint for working with nogin.nl. Requests and responses use JSON.

Base URL https://api.nogin.nl

Endpoints

GET /persons

Returns all persons and nogin.nl states.

Example request
curl https://api.nogin.nl/persons
Example response
[
  {"name": "sjaak", "isNogInNL": true},
  {"name": "harrie", "isNogInNL": false}
]
GET /persons/{name}

Returns the specific person matching the name, all persons have lowercase-only names

Example request
curl https://api.nogin.nl/persons/sjaak
Example response
{"name": "sjaak", "isNogInNL": true}
PATCH /persons/{name}

Updates an person's nogin.nl state. The request body must be an JSON encoded object/array containing 'isNogInNL' with a boolean value.

Request body
{"isNogInNL": false}
Example request
curl -X PATCH https://api.nogin.nl/persons/sjaak \
  -H "Content-Type: application/json" \
  -d '{"isNogInNL": false}'
Example response
{"name": "sjaak", "isNogInNL": false}

The API also accepts PUT for this route.

Errors

  • 400 Bad Request — the POST body is missing or invalid.
  • 404 Not Found — the item or route was not found.
Example error response
{"error": "Person not found"}
Note: This example stores items in memory. Updates are lost when the PHP server restarts.
