API reference · v1.1.0

Nogin.nl REST API

Simple endpoint for working with nogin.nl. Requests and responses use JSON. The full specification is available as OpenAPI YAML.

Base URL https://api.nogin.nl

Endpoints

GET /persons

Returns all persons and nogin.nl states.

Example request
curl https://api.nogin.nl/persons
Example response
[
  {"name": "sjaak", "isNogInNL": true},
  {"name": "harrie", "isNogInNL": false}
]
GET /persons/{name}

Returns the specific person matching the name, all persons have lowercase-only names

Example request
curl https://api.nogin.nl/persons/sjaak
Example response
{"name": "sjaak", "isNogInNL": true}
PATCH /persons/{name}

Updates a person's nogin.nl state. The request body must be an JSON encoded object/array containing 'isNogInNL' with a boolean value.

Request body
{"isNogInNL": false}
Example request
curl -X PATCH https://api.nogin.nl/persons/sjaak \
  -H "Content-Type: application/json" \
  -d '{"isNogInNL": false}'
Example response
{"name": "sjaak", "isNogInNL": false}

Errors

  • 400 Bad Request — the PATCH body is missing or invalid.
  • 404 Not Found — the item or route was not found.
Example error response
{"error": "Person not found"}
